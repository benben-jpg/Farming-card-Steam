## What is Steam Card Farming?

Steam Card Farming is the practice of running Steam games that contain Trading Cards to accumulate card drops while game playtime is being recorded. These cards can be collected, traded, or used to craft badges on Steam.

This project was created as an educational application to explore concepts such as:
- Process automation
- Desktop application development
- User interface design
- Account and session management
- Software architecture and scripting
